# ClawClimb: Risk & Reward

**ClawClimb** - це вертикальний 2D Roguelite платформер для WebGL та Android, розроблений на рушії **Unity (C#)**. Проєкт поєднує класичну механіку нескінченного підйому (в стилі Doodle Jump) з тактичним вибором апгрейдів "1 з 3" та перманентною мета-прогресією в стилі *Vampire Survivors*.

Основний акцент проєкту - **чиста архітектура**, використання **Dependency Injection (VContainer)** та масштабований **Data-Driven дизайн** систем.

*  **Пограти в WebGL демо:** [https://explxxb.itch.io/claw-climb]
*  **Платформи:** WebGL (itch.io), Android/iOS (у розробці)

## Ключові фічі та Архітектура

### 1. Геймплей та Генерація Світу
* **Динамічний вертикальний платформінг:** Процедурна генерація рівнів із 6 типами платформ (звичайні, одноразові, фейкові, а також їхні зменшені half-варіанти).
* **AI ворогів та Pickup-система:** Реалізовано логіку супротивників та пікапів.

### 2. Масштабована Система Апгрейдів (Risk & Reward)
* **Data-Driven підхід:** Система покращень повністю побудована на `ScriptableObject`. Нові негативні та позитивні ефекти додаються без зміни коду.
* **Механіка комбо-карт:** Після кожного етапу гравець обирає 1 з 3 карт. Система автоматично та випадково генерує карту, поєднуючи позитивний і негативний ефекти **однакового рангу рідкісності** (Common / Rare / Epic).

### 3. Архітектурні Паттерни та Чистий Код
* **Dependency Injection (DI):** Інтегровано фреймворк `VContainer`. Це дозволило позбутися синглтонів (`Singleton`), зменшити зв'язність коду (Low Coupling) та зробити компоненти геймплею легко тестованими.
* **Мета-прогресія та Збереження:** Перманентне прокачування характеристик між забігами. Дані серіалізуються в **JSON** для гнучкого збереження прогресу.
* **Кросплатформна Аналітика:** Налаштовано збір метрик (відсоток вибору конкретних карток та баланс ефектів) через **Unity Analytics** (для WebGL) та **Firebase Analytics** (для мобільних платформ).

## Технологічний стек

* **Рушій:** Unity 2D (C#)
* **Архітектура:** SOLID, DDD (Data-Driven Design), DI, Event-Driven Architecture
* **Інструменти / Фреймворки:** VContainer, JSON Serialization, Unity Analytics, Firebase SDK
* **Управління проєктом:** Git
